# Бот-помощник руководителя проекта

## Возможности

- Создание проектов, добавление участников
- Просмотр и управление задачами руководителем и участниками
- Предоставление участниками обратной связи по задачам
- Настройка напоминаний о дедлайнах

## Установка и запуск

1. Установить зависимости: `pip install -r requirements.txt`
2. Добавить файл `.env`, содержащий токен бота и путь к учетным данным Google Service Account:
   ```
   BOT_TOKEN='bot_token'
   GOOGLE_CREDENTIALS_PATH='path/to/credentials.json'
   ``` 
3. Запустить бота: `python3 src/main.py`

## Команды

Список доступных команд:
/start - приветственное сообщение
/help - показать список команд
/add_project - добавить новый проект
/projects - просмотреть список ваших проектов
/tasks - просмотреть ваши задачи

## Создание проекта

- Руководитель проекта создает проект командой `/add_project`. Для этого нужно создать копию шаблона Google таблицы,
  ссылку на которую даст бот. Таким образом создается новая Google таблица, которой владеет руководитель, а бот получает
  доступ к ней. После этого нужно дать доступ сервисному аккаунту (почту которого даст бот) для редактирования таблицы и
  прислать ссылку на таблицу боту. После создания проекта бот отправит deep link*
  вида https://t.me/proj_manager_assist_bot?start=project_acbdef. Эту ссылку руководитель дает участникам. Перейдя по
  ней, участники могут присоединиться к проекту. Бот также выдает ID проекта. Участники могут присоединиться к проекту
  командой `/add_project`, отправив ID проекта.
  *deep link - это ссылка, которая открывает бота и передает ему параметр. В данном случае параметр - ID проекта.
  Бот обрабатывает этот параметр и добавляет участника в проект.
- После создания проекта и добавления участников, руководитель может создавать, редактировать и удалять задачи в
  таблице.

## Задачи

Google таблица задач имеет следующий вид:

| Название | Описание | ФИО исполнителя | ТГ исполнителя | Дедлайн | Статус | Обратная связь | ID задачи |
|----------|----------|-----------------|----------------|---------|--------|----------------|-----------|

- Столбцы "ID задачи", "Обратная связь" - служебные, их не нужно заполнять

- Статусы задач:
    - `Выдана`
    - `В работе`
    - `На проверке`
    - `Завершена`

- Руководитель и участники проекта могут просматривать список проектов командой `/projects`. Бот выдаст список
  проектов, в которых они участвуют.
- Руководитель может просматривать все задачи в проекте через Google таблицу, изменять название, описание, исполнителя,
  дедлайн, статус задачи.
- Исполнители могут просматривать свои задачи через телеграм-бота командой `/tasks`. Команда выводит список задач,
  которые были выданы исполнителю. Исполнитель может перейти к задаче, нажав на кнопку соответствующей задачи. Для
  каждой задачи исполнитель может изменить статус задачи, оставить обратную связь и управлять напоминаниями о дедлайне
  по задаче.
- Чтобы изменить статус задачи, пользователь нажимает на соответствующую кнопку. Статусы могут меняться в следующем
  порядке:
    - `Выдана` -> `В работе`
    - `В работе` -> `На проверке`
    - `На проверке` -> `В работе`
- Руководитель может менять статус задачи в любой момент.

## Обратная связь

- Чтобы оставить обратную связь, пользователь нажимает на соответствующую кнопку. Текст обратной связи ограничен 200
  символами. После отправки обратной связи, она появится у руководителя в таблице.

## Напоминания

- Чтобы настроить напоминания о дедлайне, пользователь нажимает на соответствующую кнопку. Бот предложит выбрать за
  сколько до дедлайна нужно напомнить о задаче. Доступные варианты:
    - `1 минута`
    - `1 час`
    - `24 часа`
    - `1 неделя`
- После выбора времени, бот отправит напоминание в указанное время с названием и дедлайном задачи. Напоминание можно
  отключить, нажав на кнопку выбора времени еще раз. Таким образом кнопки переключаются между состояниями "активно" и "
  неактивно".

``````
│       ├── reminder.py         # Управление напоминаниями
│       └── task.py             # Управление задачами
├── gsheets/
│   ├── client.py               # Взаимодействие с Google Sheets API
│   └── sync_service.py         # Сервис синхронизации данных с таблицами
├── reminders/
│   └── reminder_service.py     # Сервис отправки уведомлений о дедлайнах
└── utils/
    ├── README.md               # Документация по утилитам
    ├── helpers.py              # Вспомогательные функции
    ├── messages.py             # Шаблоны сообщений
    └── storage.py              # Логика хранения данных
``````
